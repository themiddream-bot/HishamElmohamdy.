# منصة مستر هشام المحمدي

## نسخة Netlify

Netlify لا يشغّل `server.mjs` وقاعدة SQLite المحلية كخادم دائم. نسخة Netlify تستخدم Function في `netlify/functions/api.mjs` وقاعدة PostgreSQL على Supabase.

1. أنشئ مشروعاً على Supabase، ثم افتح SQL Editor وشغّل محتوى `supabase/schema.sql` مرة واحدة.
2. ارفع مجلد `outputs` إلى مستودع Git واربط المستودع بـ Netlify، أو انشره باستخدام Netlify CLI. إعدادات البناء موجودة في `netlify.toml`؛ أمر البناء يجهز مجلد `dist` ووظيفة API. رفع `dist` وحده بالسحب والإفلات لا يرفع وظائف الخادم.
3. في إعدادات Netlify أضف متغيرات البيئة التالية، واجعلها متاحة لوظائف Netlify:
   - `SUPABASE_URL`: عنوان مشروع Supabase.
   - `SUPABASE_SECRET_KEY`: مفتاح Supabase السري الذي يبدأ بـ `sb_secret_`.
   - `SESSION_SECRET`: سلسلة عشوائية طويلة لتوقيع جلسات الدخول.
   - `ADMIN_PASSWORD`: كلمة مرور الأدمن الأولية.
4. أعد النشر. ينشئ أول طلب API حساب الأدمن `abdelrahmanyasser` باسم `Abdelrahman Yasser`. عيّن `ADMIN_PASSWORD` قبل أول زيارة للموقع.

المفتاح السري يُحفظ في إعدادات Netlify فقط ولا يوضع في ملفات الموقع أو المتصفح. Supabase يوصي بإرسال المفاتيح الجديدة `sb_secret_` في ترويسة `apikey` دون ترويسة Bearer؛ الوظيفة تفعل ذلك تلقائياً. [مفاتيح Supabase](https://supabase.com/docs/guides/getting-started/api-keys)

للنشر اليدوي من PowerShell بعد تثبيت Netlify CLI وتسجيل الدخول، شغّل من مجلد `outputs`:

```powershell
netlify deploy --build --prod
```

إعدادات متغيرات Netlify لوظائف الخادم موثقة [هنا](https://docs.netlify.com/build/functions/environment-variables/)، والنشر من CLI موضح في [دليل Netlify](https://docs.netlify.com/api-and-cli-guides/cli-guides/get-started-with-cli/).

موقع تعليمي بخادم Node.js وقاعدة بيانات SQLite. لا يحتاج تثبيت حزم npm خارجية.

## تشغيل محلي

يتطلب Node.js 24 أو إصداراً أحدث. افتح PowerShell داخل مجلد الموقع وشغّل:

```powershell
$env:ADMIN_PASSWORD = 'ضع-كلمة-مرور-قوية-هنا'
npm start
```

ثم افتح `http://localhost:3000`. ينشئ الخادم قاعدة البيانات تلقائياً في `data/platform.sqlite`.

اسم مستخدم الأدمن هو `abdelrahmanyasser` ويظهر باسم `Abdelrahman Yasser`. كلمة مروره هي القيمة التي وضعتها في `ADMIN_PASSWORD` عند أول تشغيل؛ محلياً فقط، إذا لم تحددها، يستخدم الخادم `Abdelrahman123`.

## النشر

- ارفع محتويات مجلد `outputs` إلى خدمة استضافة تدعم Node.js 24 وملفات SQLite دائمة.
- أمر البدء: `npm start`، والمنفذ يقرأه التطبيق من `PORT`.
- عيّن `NODE_ENV=production` و`ADMIN_PASSWORD` كمتغيرات سرية في لوحة الاستضافة. يرفض الخادم بدء وضع الإنتاج دون كلمة مرور أدمن محددة.
- اربط قرصاً دائماً على `/app/data` أو عيّن `DATABASE_PATH` إلى مسار على قرص دائم. قاعدة SQLite تحتاج قرصاً محلياً دائماً؛ قواعد بيانات الخوادم المؤقتة لن تحفظ البيانات بعد إعادة التشغيل.
- اربط نطاقاً وفعّل HTTPS من خلال الاستضافة أو وكيلها. ملفات الواجهة وخدمات Google Fonts وFont Awesome تحتاج اتصال إنترنت.

## قاعدة البيانات والوظائف

قاعدة البيانات تحفظ الطلاب وكلمات المرور المشفّرة وصور الملفات الشخصية والأرصدة والأكواد والحصص والمشتريات وتقدم المشاهدة. سعر كل حصة ٥٠ جنيهاً. متعقب YouTube وVimeo يسجل وقت التشغيل الفعلي على فترات قصيرة، ويعرض للأدمن دقائق المشاهدة والنسبة المسجلة من مدة الفيديو لكل طالب وحصة. الجلسات تستخدم ملفات تعريف ارتباط `HttpOnly` وتبقى داخل ذاكرة الخادم؛ بعد إعادة تشغيله يسجّل المستخدمون الدخول مجدداً. الأكواد أحادية الاستخدام، وخصم سعر الحصة وتسجيل شرائها يجريان داخل معاملة قاعدة بيانات.

قبل فتح التسجيل للعامة، اضبط إعدادات الاستضافة والقرص الدائم وكلمة مرور الأدمن. هذه الحزمة لا تنشئ حساب دفع إلكتروني؛ شحن الرصيد يتم بأكواد يصدرها الأدمن.
